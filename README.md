# Hub de marketing com Claude Code

Skills e contexto das empresas para criar estratégia, conteúdo de Instagram, anúncios, landing pages e cartas de venda.

## Usar

```bash
git clone https://github.com/olivermatheus-dev/skills.git
cd skills
claude
```

As skills ficam em `.claude/skills/` e carregam sozinhas ao abrir o Claude Code nesta pasta. Não há instalação.

Para exportar carrosséis em PNG (uma vez): `npm i`.

## Exemplos de pedido

- `nova empresa: <nome>` → cria o contexto
- `10 ideias de conteúdo para a kz`
- `roteiro de reels sobre faltas de pacientes`
- `transforma esse roteiro em carrossel`
- `cria 3 ângulos de anúncio para o lançamento da kz`
- `escreve a carta de vendas da kz`
- `analisa esse CSV de resultados dos anúncios`
- `plano de lançamento de 6 semanas`

Veja `CLAUDE.md` para a estrutura e a lista de skills. Roadmap de evolução do hub em `roadmap/BACKLOG.md`.
