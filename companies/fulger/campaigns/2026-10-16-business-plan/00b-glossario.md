# Glossário

| termo | em português claro |
|---|---|
| **Ativação** | o professor fez o mínimo que mostra uso real: cadastrou 3 alunos e marcou 1 aula |
| **CAC** | custo para conquistar um cliente pagante (anúncio, brinde, tempo) |
| **LTV** | receita líquida que um cliente deixa durante toda a assinatura |
| **Cancelamento mensal (churn)** | a porcentagem de clientes que cancela a cada mês |
| **TAM, SAM e SOM** | mercado total · a parte que o Fulger consegue atender · a parte que dá para conquistar de verdade |
| **Receita recorrente anual** | quanto as assinaturas rendem em 12 meses |
| **Nível de consciência (Schwartz)** | o quanto o cliente já sabe do problema e da solução, do "não sei que tenho um problema" ao "sei qual produto quero" |
| **Sofisticação do mercado** | quantas promessas parecidas o cliente já ouviu. No nível 3, a promessa sozinha não convence mais: precisa de um mecanismo novo |
| **Ideia central** | a ideia única que organiza toda a comunicação (*big idea*, no jargão) |
| **Pilha de valor** | a lista do que vem na oferta, item por item, antes do preço |
| **Van Westendorp** | pesquisa de preço com 4 perguntas (caro demais, caro, barato, barato a ponto de desconfiar) |
| **MVP** | a primeira versão do produto com o mínimo que resolve o problema |
| **Publicação** | colocar o produto no ar para uso real (*deploy*) |
| **Plano grátis permanente** | uso sem pagar, com limite (*freemium*) |
| **Videochamada direta (WebRTC)** | a chamada vai de um aparelho ao outro sem passar pelo servidor |
| **Relay (TURN, coturn)** | quando a rede do aluno bloqueia a chamada direta, ela passa pelo nosso servidor, e é aí que gasta banda |
| **VPS** | servidor alugado onde o Fulger roda |
| **Anúncio para quem visitou** | anúncio mostrado só para quem já entrou no site ou na fila (*retargeting*) |
| **Ângulo** | a dor ou o desejo que o anúncio ou o post usa para chamar a atenção |
| **Gancho** | a primeira frase ou os primeiros segundos de um post ou vídeo |
| **Reels, Stories, lives** | formatos do Instagram: vídeo curto, conteúdo de 24 h, transmissão ao vivo |
| **UGC** | vídeo gravado por um cliente ou por alguém "comum", não pela marca |
| **Canais próprios, alugados e emprestados** | os nossos (site, lista) · as redes sociais · o público de parceiros |
| **Fila de acesso antecipado** | a lista de quem pediu para testar o Fulger no site |
| **Fundador** | quem assina na abertura, com preço especial enquanto a assinatura durar |
